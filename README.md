# Travel Frog: China Journey

[Play online](https://fionviber.github.io/WebTF/)

The original Simplified Chinese edition is preserved.

This edition runs in the browser and uses local saves. Export a save before changing browsers, devices, or site addresses. No application backend, account, database, or paid service is needed.

Publish the repository root as a static site. Keep all asset folders and .nojekyll. A local preview needs a static HTTP server; opening index.html through file:// is unsupported.

Original game and artwork belong to their respective owners. Original notices are retained.
